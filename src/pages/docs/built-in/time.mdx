# Intro

`KIN_IGIHE` is a **namespace** (not a function — do not write `KIN_IGIHE()`). Its methods read the current clock.

## How to

- `KIN_IGIHE.isaha()` : Returns current time as `HH:mm:ss` (24-hour clock), e.g. `"14:05:09"`
- `KIN_IGIHE.umunsi()` : Returns the English weekday from moment, e.g. `"Monday"`, `"Tuesday"` (not Kinyarwanda names)
- `KIN_IGIHE.itariki()` : Returns the current date as `Do MMM YY`, e.g. `"10th Aug 26"` — **not** `YYYY-MM-DD`
