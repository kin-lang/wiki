# Intangiriro

**Loops** zikoreshwa mu gusubiramo igice cya **code** igihe **condition** runaka ari ukuri.

## Imiterere (Syntax)

```Kin
subiramo_niba (condition) {
  # igice cya code kizakorwa
}
```

## Urugero

```Kin
reka x = 0
subiramo_niba (x < 100) {
  x = x + 1
  tangaza_amakuru(x)
}
```

> Iyi code izandika 1, 2, 3, ..., 98, 99, 100

**Condition** ishobora kuba **complex** uko ushaka!

## Guhagarika uruziga na `hagarara`

Mu `subiramo_niba`, andika `hagarara` kugira ngo uve mu kigeragezo ako kanya. Akadomo `;` nyuma yacyo si ngombwa. Iki ni **ijambo ry’ingenzi** (break), si `hagarara(0)` yo guhagarika porogaramu ya Kin.

```Kin
reka i = 1
subiramo_niba (i <= 100) {
  tangaza_amakuru(i)
  niba (i == 5) {
    hagarara
  }
  i = i + 1
}
```

> Ibi byandika 1, 2, 3, 4, 5 hanyuma bihagarara.

## Gusimbuka kigeragezo na `komeza`

Mu `subiramo_niba`, andika `komeza` kugira ngo usimbuke ibisigaye by’ako kigeragezo hanyuma usuzume condition inshuro ikurikira. Akadomo `;` nyuma yacyo si ngombwa. `komeza` ikoreshwa **gusa** mu kizunguruka (si muri porogaramu_ntoya yahamagajwe gusa kuva mu kizunguruka).

```Kin
reka i = 0
subiramo_niba (i < 5) {
  i = i + 1
  niba (i == 3) {
    komeza
  }
  tangaza_amakuru(i)
}
```

> Ibi byandika 1, 2, 4, 5 (3 irasimbutswe).
