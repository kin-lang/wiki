# Intangiriro

**Iminduragaciro** ni ibikoresho byo **kubika amakuru**.

Muri **_Kin_**, iminduragaciro zishobora gutangazwa mu buryo bubiri:

## `reka`

Iyo utanze ihinduragaciro ukoresheje ijambo ry’ingenzi `reka`, ushobora guhindura agaciro ka ryo nyuma muri porogaramu.

```Kin
reka x = value
```

Ihinduragaciro `x` iratangazwa kandi yahawe n'agaciro ka `value`, ariko ako agaciro gashobora guhindurwa nyuma muri porogaramu.

Nanone, ushobora gutanga ihinduragaciro ntuyihe agaciro:

```Kin
reka x;
```

> Muri iki gihe, ihinduragaciro `x` iratangazwa ariko nta gaciro yahawe.
> **Icyitonderwa:** Ugomba kongeraho akadomo n'akitso **_(;)_** ku iherezo ry’iyi nteruro(statement).

## `ntahinduka`

Iyo utanze ihinduragaciro ukoresheje ijambo ry’ingenzi `ntahinduka`, ntabwo ushobora guhindura agaciro kayo nyuma muri porogaramu.

```Kin
ntahinduka x = 10
```

> Ntushobora guhindura agaciro k'ihinduragaciro `x` nyuma muri porogaramu.

> **Icyitonderwa:** Ugomba guha agaciro variable idahinduka, bityo ibi ntibizakora:

```Kin
ntahinduka x; # Bizatera ikibazo
```

## Ubwoko bw'ihinduragaciro

Ushobora gushyira **ikirango cy'ubwoko** nyuma y'izina ry'ihinduragaciro.
Ibyo bituma **kugenzura ubwoko** mu gihe porogaramu ikora (igihe utangaza no
iyo uhindura agaciro), iyo ubwoko bugenewe bukora (uburyo bw'ibanze: `on`).

```Kin
reka age: number = 25
reka name: string = "Keza"
ntahinduka PI: number = 3.14
```

### Ubwoko ngombwa n'ubwoko bushoboka

| Imiterere | Icyo bisobanura |
|-----------|-----------------|
| `: type` | **Ngombwa** — agaciro kigomba kuba ubwo ubwoko; `ubusa` ntiyemerewe |
| `: type?` | **Bishoboka** — agaciro gashobora kuba ubwo ubwoko **cyangwa** `ubusa` |

```Kin
reka score: number = 10     # umubare ngombwa
reka maybe: number? = ubusa # umubare ushobora kuba ubusa
reka later: string?;        # string ishoboka, itangira nk'ubusa
```

### Amazina y'ubwoko

Amazina yemewe: `number`, `string`, `boolean`, `object`, `urutonde`, `fn`,
na `native-fn` (ni izina risa na `fn`).

**Icyitonderwa:** `ubwoko` ikomeza kugaragaza izina rya `ubwoko`. Imirimo
yubatsemo nka `tangaza_amakuru` igaragaza `"native-fn"`, naho imirimo ya
ukoresha igaragaza `"fn"`. Mu kirango cy'ubwoko, `fn` ikubiyemo **byombi**.

### Gukoresha cyangwa guhagarika kugenzura ubwoko

| Uburyo | Icyo bisobanura |
|--------|-----------------|
| `on` (ibanze) | Iminduragaciro ifite ikirango igenzurwa; idafite ikomeza guhinduka |
| `off` | Nta kugenzura — ibirango by'ubwoko ntibikoreshwa |
| `strict` | Buri `reka` / `ntahinduka` **igomba** kugira ikirango cy'ubwoko |

Ushobora gushyira uburyo mu:

1. CLI: `kin run --types off dosiye.kin` cyangwa `--types strict`
2. Mu dosiye: `# kin-types: off` cyangwa `# kin-types: strict`
3. Env: `KIN_TYPES=off` cyangwa `KIN_TYPES=strict`

## Amazina yubatsemo

Kin itanga kandi amazina abiri utatangaza:

- `filename` — **ijambo**: inzira ya dosiye `.kin` irimo gukorwa. `KIN_INYANDIKO` ishyira inzira igoye ku bubiko bwayo.
- `ikosa` — izina rihinduka, ritangira riri `ubusa`. Ryateganyijwe kubika ikosa; runtime ntiyandikamo ubwayo ubu.
