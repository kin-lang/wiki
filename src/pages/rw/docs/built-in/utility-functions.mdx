# Intangiriro

Uru ni urutonde rw’ibindi byubatsemo tutigeze tuvugaho muri iyi documentation.

# Ibindi bizwi hose

## `filename`

Ni **ijambo** (string), si umumaro: inzira ya dosiye wahaye `kin run`, cyangwa ububiko bwa REPL.

Buri murimo wa `KIN_INYANDIKO` ushyira inzira igoye ku bubiko `filename` irimo. Andika `filename`, si `filename()`.

```Kin
tangaza_amakuru(filename)
```

## `ikosa`

Ni ihinduragaciro rusange rihinduka, ritangira riri `ubusa`. Ryateganyijwe kubika ikosa. Runtime ntiyandikamo ubwayo ubu — porogaramu yawe ni yo ishobora kuryiha agaciro.

# Method

## `ubwoko` (ikimenyetso cya mbere cy’ubwoko)

`ubwoko` ni **ijambo ry’ingenzi / ikimenyetso cya mbere** (gishira imbere y’ibimenyetso bya binary). Gisubiza **agaciro k’ubwoko**, si ijambo:

- Ku bintu bya primitive n’ibindi: tags zisa, nuko `ubwoko 5 == ubwoko 10` ari nibyo.
- Ku instance y’imiterere: agaciro k’imiterere (`ubwoko keza == Umuntu`).
- Porogaramu_ntoya n’imirimo ya sisiteme bafite ubwoko bumwe bwa `fn`.
- `ubwoko(x)` mu makugiro biracyakora.

Iyo byanditswe, agaciro k’ubwoko kagaragaza amazina nka `number`, `string`, `urutonde`, `fn`, `class`.

Urugero:

```Kin
reka x = 5
tangaza_amakuru(ubwoko x)
tangaza_amakuru(ubwoko [1, 2])
tangaza_amakuru(ubwoko 5 == ubwoko 10)
```

> Bisohora `number`, hanyuma `urutonde`, hanyuma `nibyo`.

Soma kandi [Imiterere (OOP)](/rw/docs/language-structure/Classes).

## `sisitemu()`

Ikoresha itegeko rya shell y’imashini yawe kandi isubiza stdout yayongewe nk’ijambo.

**Ingaruka:** iryo tegeko rikora n’uburenganzira bwawe. **Ntushyiremo** inyandiko utizeye, kandi ntukoreshe urugero nka `sudo shutdown now` mu kwiga.

```Kin
reka out = sisitemu("echo muraho")
tangaza_amakuru(out)
```

> Byandika `muraho`.

## Guhagarika uruziga

`hagarara` ni **ijambo ry’ingenzi** riva muri `subiramo_niba`. Si `hagarara(0)` yo guhagarika porogaramu ya Kin. Reba [Ibyisubiramo](/rw/docs/language-structure/Loops).
