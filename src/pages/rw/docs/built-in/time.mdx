# Intangiriro

`KIN_IGIHE` ni **umuryango** (si umumaro — ntukandike `KIN_IGIHE()`). Imimaro yayo isoma isaha iriho.

## Uko bikorwa

- `KIN_IGIHE.isaha()` : Isubiza isaha mu buryo `HH:mm:ss` (amasaha 24), urugero `"14:05:09"`
- `KIN_IGIHE.umunsi()` : Isubiza izina ry’umunsi mu Cyongereza, urugero `"Monday"`, `"Tuesday"` (si *Kuwa Mbere*)
- `KIN_IGIHE.itariki()` : Isubiza itariki mu buryo `Do MMM YY`, urugero `"10th Aug 26"` — **si** `YYYY-MM-DD`
