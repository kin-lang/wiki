## Kwinjiza (Installation)

Kin iboneka binyuze muri **npm package manager**, ushobora kuyinjiza ukoresheje:

```bash
# npm
npm i -g @kin-lang/kin

# yarn
yarn add -g @kin-lang/kin

# pnpm
pnpm add -g @kin-lang/kin
```

> Koresha `kin --version` urebe niba **_Kin_** yinjijwe neza.
> Ku bakoresha **_Linux Distros_** na **_macOS_**, ntuzibagirwe gukoresha **_sudo_**.

## Kwihuza na IDE (IDE Integrations)

[Inyongera ya Visual Studio Code](https://marketplace.visualstudio.com/items?itemName=pacifiquem.kinlang) (shakisha **kinlang**) igezaho:

- Gukaranga imirongo ya `.kin` (syntax highlighting)
- Kwerekana amakosa y'inyandiko ako kanya (diagnostics)
- Gutanga ibisubizo (completions) ku magambo-ngenga, ibikoresho bya Kin, n'amazina uri gukoresha
- Hover na signature help: icyo buri function ikora n'icyo buri argument isobanura

Winjize extension, ufungure dosiye ya `.kin`. Gukoresha porogaramu (`kin run file.kin`) bikiri bisaba CLI iri hejuru.

Suzuma amakosa y’inyandiko nta gukoresha porogaramu:

```bash
kin check filename.kin
```

## Porogaramu ya Mbere

Kora dosiye ifite inyongera `.kin`, wandikemo aya mabwiriza kugira ngo porogaramu ya mbere **Hello World** ikore:

```kin
reka name: ijambo = injiza_amakuru("Izina ryawe ni irihe? ")
tangaza_amakuru("Muraho, ", name, "!")
```

Koresha porogaramu yawe unyura aho dosiye iherereye kuri sisiteme yawe, hanyuma ukore:

```bash
kin run filename.kin
```

> Menya neza ko **Kin** yinjijwe kandi uri mu bubiko bukwiye (correct directory).
